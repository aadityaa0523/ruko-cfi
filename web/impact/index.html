Do people get better at spotting scams?

The spot-the-scam test: six messages before and six different messages after learning the four signs of a scam. Which set comes first is random for each person, so a harder set cannot fake an improvement. Only people who finished both rounds are compared, each with themselves.

How this is counted

  • Each browser gets a random id the first time it uses Ruko. We count ids, so one person on two devices counts twice, and a family sharing one phone counts once.
  • Stored per event: that id, what happened (for example "message checked"), the language, the verdict, and the quiz score. Never the message, a phone number, a name or an IP address. The connection is stored only as a scrambled code, to block abuse and count distinct connections.
  • Not counted: our own testing (localhost, or any browser that opened a Ruko page with ?test=1). Limits stop one connection or device from flooding the numbers, and each device's quiz counts once.
  • The success rules were written down before counting began, in docs/IMPACT_PLAN.md in Ruko's public repository, with the date in its history.
